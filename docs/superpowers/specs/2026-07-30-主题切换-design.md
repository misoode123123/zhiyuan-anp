# 主题切换（亮/暗）

> 日期:2026-07-30 ｜ 状态:待评审

## 1. 背景与目标

ANP 平台前端（Next.js + Tailwind v4）当前强制浅色（`globals.css` 原 `color-scheme: light` + 固定 `#fafafa`，后调柔和蓝灰 `#f1f3f5`）。全仓 0 处 `dark:` 用法，20+ 页面用 `bg-white` + 大量硬编码中性色，无主题切换能力。用户反映"太白太亮"，已先做柔和亮色（已上线），现在要补完整的亮/暗主题切换。

**目标**：加亮/暗两主题 + 右上角切换开关 + localStorage 持久化 + 首次跟随系统。暗色用蓝灰暗调，与现有浅色蓝灰呼应。通用组件全适配暗色，页面内零散硬编码色用语义 token 替换。

## 2. 已确认的需求边界

| 维度     | 选择                                                             |
| -------- | ---------------------------------------------------------------- |
| 覆盖深度 | 框架 + 通用组件全适配（页面内零散硬编码色用 token 替换，逐步迁） |
| 暗色配色 | 蓝灰暗（呼应浅色蓝灰）                                           |
| 默认主题 | 跟随系统（prefers-color-scheme）+ 手动覆盖（localStorage）       |
| 切换开关 | shell 顶栏 user-switcher 旁，太阳/月亮图标                       |
| 不含     | opencode iframe 主体、图表配色、品牌装饰色                       |

## 3. 主题变量体系与 Tailwind 映射

### 3.1 语义变量（globals.css）

8 个语义变量 + 3 个状态色，浅色在 `:root`、暗色在 `.dark`：

| 变量           | 浅色值    | 暗色值    | 用途                |
| -------------- | --------- | --------- | ------------------- |
| `--bg`         | `#f1f3f5` | `#1a1d21` | 主背景（body）      |
| `--surface`    | `#ffffff` | `#25292e` | 卡片/面板/侧栏底    |
| `--surface-2`  | `#f3f4f6` | `#2d3239` | hover/次级面/嵌套区 |
| `--text`       | `#171717` | `#e4e6eb` | 主文字              |
| `--text-muted` | `#6b7280` | `#9ca3af` | 次要文字/占位       |
| `--border`     | `#e5e7eb` | `#33373c` | 分隔线/边框         |
| `--accent`     | `#2563eb` | `#3b82f6` | 强调（品牌蓝）      |
| `--accent-fg`  | `#ffffff` | `#ffffff` | 强调上的文字        |
| `--danger`     | `#cf222e` | `#f87171` | 错误/阻断           |
| `--success`    | `#2da44e` | `#3fb950` | 成功                |
| `--warn`       | `#d29922` | `#e3b341` | 警告                |

### 3.2 Tailwind v4 映射

`@theme inline` 把变量映射成 Tailwind 颜色 token，组件即可用 `bg-surface`/`text-text`/`border-border` 等类：

```css
@theme inline {
  --color-bg: var(--bg);
  --color-surface: var(--surface);
  --color-surface-2: var(--surface-2);
  --color-text: var(--text);
  --color-text-muted: var(--text-muted);
  --color-border: var(--border);
  --color-accent: var(--accent);
  --color-accent-fg: var(--accent-fg);
  --color-danger: var(--danger);
  --color-success: var(--success);
  --color-warn: var(--warn);
}
```

### 3.3 关键约束

- `body` 用 `background: var(--bg); color: var(--text)`。
- 旧变量 `--background`/`--foreground` 保留为 `--bg`/`--text` 别名，避免破坏现有引用。
- `color-scheme` 由 class 驱动：`:root { color-scheme: light }`、`.dark { color-scheme: dark }`，原生表单元素（scrollbar/input）自动跟随。

## 4. 主题切换机制

### 4.1 防 FOUC（关键）

Next.js App Router SSR 时服务器不知主题，若 hydration 后才设 class 会闪浅色。在 `app/layout.tsx` 的 `<head>` 注入同步 inline script，HTML 解析时即执行：

```js
(function () {
  try {
    var t = localStorage.getItem("anp.theme");
    var dark = t ? t === "dark" : matchMedia("(prefers-color-scheme: dark)").matches;
    document.documentElement.classList.toggle("dark", dark);
  } catch (e) {}
})();
```

### 4.2 ThemeProvider（`lib/theme.tsx`，`'use client'`）

- React context，暴露 `theme: 'light'|'dark'` 与 `toggle()`。
- 挂载时读 `<html>` 当前 class（inline script 已设）作初始值，避免 SSR/CSR 不一致。
- `toggle()`：翻转 `html.dark` class + 写 `localStorage['anp.theme']` + setState。
- 系统实时跟随：用户未手动选（无 localStorage）时，监听 `matchMedia('(prefers-color-scheme: dark)')` change 事件实时跟随；手动选后停止跟随。
- 包在 `app/layout.tsx` 的 `<body>` 最外层。

### 4.3 ThemeToggle 组件（`app/_components/theme-toggle.tsx`）

- `'use client'`，太阳/月亮 SVG 图标按钮，放 `shell.tsx` 顶栏 `user-switcher` 旁。
- 点击调 `useTheme().toggle()`，图标随当前主题切换。
- 纯展示 + 调 context，无副作用。

### 4.4 数据流

```
首次访问: inline script(同步) → html.dark 设好 → React 挂载 → ThemeProvider 读 html class 初始 → 无闪烁
用户点开关: toggle() → 翻转 html.dark + localStorage 持久化 + setState → 图标切换 + 全局色变
再次访问: inline script 读 localStorage → 用上次选择
```

### 4.5 关键约束

- inline script 必须在 `<head>` 且同步（不能用 React effect，否则闪）。
- localStorage key = `anp.theme`，值 `'light'`/`'dark'`；不存 `'system'`，系统态由"未设 key"表示。
- ThemeProvider 是 `'use client'`，`layout.tsx` 本身可保持 server component（Provider 作 client 子组件嵌入）。

## 5. 适配范围与策略（三层）

### 5.1 层 1 — 框架骨架（`app/_components/`）

- `shell.tsx`：侧栏 `bg-[#f7f8fa]` → `bg-surface`、边框 `border-neutral-200` → `border-border`、顶栏同。
- `tabs.tsx`/`tab-bar.tsx`：标签栏背景/激活态/文字 → token。
- `notif-bell`/`user-switcher`/`workspace-switcher`：下拉/文字色 → token。
- `theme-toggle.tsx`（新）：开关本身 `bg-surface-2 text-text`。

### 5.2 层 2 — 全局表单兜底（`globals.css`）

原生表单元素散落各页面，逐个改不现实。加基础规则：

```css
input,
select,
textarea {
  background: var(--surface);
  color: var(--text);
  border-color: var(--border);
}
input::placeholder,
textarea::placeholder {
  color: var(--text-muted);
}
```

所有页面 `<input>/<select>/<textarea>` 自动跟主题，零页面改动。

### 5.3 层 3 — 页面卡片（20+ 页面）

机械替换：

- `bg-white` → `bg-surface`
- `text-neutral-700/900` → `text-text`/`text-text-muted`
- `border-neutral-200` → `border-border`
- `hover:bg-[#e8e8e8]`/`hover:bg-neutral-100` → `hover:bg-surface-2`
- 状态色 `bg-[#cf222e]` → `bg-danger`、`text-[#1a7f37]` → `text-success` 等

跨 20 页面批量机械替换，可脚本辅助 + 逐页 tsc 验证。

### 5.4 workspace 编码工作台

- 活动栏 `bg-white`/sidebar `bg-[#f3f3f3]` → token；各 view 列表/hover → token。
- **opencode iframe 主体不受平台主题控制**（第三方 iframe），明确不含。

### 5.5 关键约束

- 适配以"背景/文字/边框/hover"四类中性色为主，状态色用 token 映射。
- 不动图表/可视化配色（compute/performance 页），暗色下若不可读留下期微调。
- 每页改完跑 `pnpm tsc`，整体 `pnpm build` 26 页过。

## 8. 验收标准

1. shell 右上角有主题开关，点击亮↔暗切换，图标随之变。
2. 刷新页面无闪烁（inline script 同步设 class）。
3. 切换后 localStorage 记住，再次访问保持。
4. 首次访问（清 localStorage）跟随系统主题。
5. 暗色下：侧栏/顶栏/卡片/表单/表格/按钮/文字/边框均可读、对比度够。
6. 浅色下：与改造前视觉一致（回归不破）。
7. `pnpm tsc` + `pnpm build` 26 页通过；`lib/theme.test.ts` PASS。
