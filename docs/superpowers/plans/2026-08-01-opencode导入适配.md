# opencode 导入适配 实现计划（v1）

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans（inline）或 subagent-driven-development。Steps 用 `- [ ]` 跟踪。

**Goal:** 导入后由 opencode/claude（经 `CodingAgent`）适配应用 to ANP：改应用代码（config 走 env/Dockerfile/端口）+ 经 ANP 受控供给缺失服务（v1 报缺+审批装）。v1 范围：AGENTS.md 适配规范 + 导入触发 opencode 适配（改码）；缺失服务供给 v1b 随后。

**Architecture:** `BuildAgentsMarkdown` 追加「ANP 部署适配规范」段（ANP 上下文）；appdeploy 经 `AdaptSubmitter` 接口（`dev.CodingAgent` 实现）在导入 goroutine 末尾触发 `RefreshAgentsMD` + `Submit("adapt",...)`；opencode 读 repo+AGENTS.md 自主改码 → 自动 commit+变更请求 → 审批 → 构建/部署。

**Tech Stack:** Go（`internal/standard` + `internal/appdeploy` + `internal/dev` + `cmd/server`）。

**Spec:** `docs/superpowers/specs/2026-08-01-opencode导入适配-design.md`

**§10 决议（按推荐 default）**：导入后自动触发一次 + 详情可重试；缺失服务供给 v1（报缺+审批后 `ProvisionNode` 装）；白名单=标准中间件（不含系统包）；AGENTS.md 适配规范全局默认+项目级覆盖。

### Task 3: 适配 prompt 模板

**Files:** Create `internal/appdeploy/adapt_prompt.go`

- [ ] **Step 1: 实现** —

```go
package appdeploy

// AdaptPrompt 导入后让 opencode 把应用适配成可在 ANP 部署运行的指令。
// 结合仓库内的 AGENTS.md（含 ANP 部署适配规范）一起喂给 opencode。
func AdaptPrompt(appName string) string {
	return "把本仓库的应用「" + appName + "」适配成能在 ANP 平台部署运行。" +
		"严格按仓库根 AGENTS.md 的「ANP 部署适配规范」改：" +
		"配置改为优先读环境变量（禁硬编码 127.0.0.1/localhost 访问中间件）、" +
		"确保仓库根有可构建的多阶段 Dockerfile 并 EXPOSE 监听端口、" +
		"所需中间件不要写死地址（由 ANP 注入 env）。" +
		"若部署机缺某依赖服务，在变更说明里报明缺什么（kind/原因）。" +
		"改完提交，说明里列出改了哪些文件、为什么。"
}
```

- [ ] **Step 1: 在 Import goroutine 收尾（`provisioner.Provision` 之后）追加**：

```go
	// 导入后触发 opencode 适配（改应用代码 to ANP；best-effort，失败不阻塞导入）。
	if h.adaptSubmitter != nil {
		if h.standards != nil {
			_ = h.standards.RefreshAgentsMD(ctx, repoDir, psID, "")
		}
		// 适配是异步任务（Submit 内部 goroutine），导入不阻塞；用 context.Background 派生，避免 HTTP ctx 取消。
		_, _ = h.adaptSubmitter.Submit(context.Background(), psID, "system", "adapt", appID, repoDir, AdaptPrompt(name), "")
	}
```
