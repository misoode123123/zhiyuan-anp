# 导入已有项目 · 实现记录

日期：2026-07-27
分支：`feat/import-existing-project`（base ef878c5）
配套：[PRD](../PRD/2026-07-27-导入已有项目-PRD.md) · [实现计划](../superpowers/plans/2026-07-27-导入已有项目.md)

## 1. 实现概览

把已有代码项目（远程 git 仓库 / 本机 zip / 服务器目录）导入 ANP 托管仓 `/data/repos/<name>`，落地为 `managed` Application（`import_source` 标记来源），复用 AI 编码/审批/部署全流程。9 个 TDD task + 每任务 review + final whole-branch review + final fix。

## 2. 数据模型（迁移 000021）

`appdeploy_application` 加 3 列：

- `import_source`（''/git/dir）、`import_ref`（git=url/dir=标识）、`imported_at`（完成时间，进行中 NULL）

复用 `status` 列承载导入态（`importing → registered/failed`），不新加状态机字段。

## 3. 后端

- `repo.go`：`ImportFromGit`（git clone，私有 HTTPS 用 `-c http.extraHeader` 注入 token；SSH 走部署机 key）/ `ImportFromZip`（防 zip slip + bomb，**按实际解压字节累计 + io.LimitReader 兜底**，不依赖 lying header）/ `ImportFromDir`（白名单 `["/data/","/opt/legacy/"]` + `Clean`+`ToSlash` 防穿越）。
- `handler.go`：`POST /project-spaces/:id/import/apps`（JSON git/dir）+ `/import/apps/upload`（multipart zip）；异步 `runImport`/`runImportZip`（`context.Background()` + 30min 超时，禁 request ctx）；失败 `os.RemoveAll` + `SetStatus failed`；token 写 `last_error` 前 `ReplaceAll` 脱敏（空 token 判空）。
- `store.go`：`appCols`/`Create` 加列；新增 `UpdateImportDone`。

## 4. 前端

`/applications` 加「📥导入已有项目」入口 + 3 步向导（选来源→填信息→执行轮询）+ 来源徽章（📥git/📁目录）。轮询用 `useRef` cancellation token（修 stale closure bug）。`api-types.ts` 重新生成含两导入路径。

## 5. 偏离 PRD 之处（实现细化）

| 点                | PRD                       | 实现                                      | 原因                                                     |
| ----------------- | ------------------------- | ----------------------------------------- | -------------------------------------------------------- |
| 导入路由          | `/apps/import`            | `/import/apps`                            | Gin 同层字面量 `import` 与参数 `:aid` 冲突会 panic       |
| `ManagedRepoBase` | const                     | const→var                                 | 测试用 `t.TempDir()` 覆盖（本机 Windows 无 /data/repos） |
| 进度载体          | 新增 UpdateImportProgress | 复用 `SetStatus`（status+last_error）     | DRY，不新增方法                                          |
| 本地 git_url 校验 | 严格 `Host!=""`           | 远程 http(s)/git@ 放行 + 本地路径走白名单 | 跨平台（ToSlash）+ 防绕过 dir 白名单                     |
